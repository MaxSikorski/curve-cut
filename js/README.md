# js/ — who owns what

Classic scripts (no modules, no build step) loaded in order by `index.html`; everything hangs off `window.CurveCut` (`CC`). Files ending in `-core.js` are DOM-free so the headless checks in `tests/` can cover them; their UI lives in the file without `-core`.

| File | What it owns |
|---|---|
| `app.js` | Viewer shell: scene, model loading (STL/OBJ/3MF), orbit and snap views, theme, drag-and-drop, progress pill |
| `ops.js` | Operation coordinator: one structural async job at a time (`CC.ops.begin/end/busy`) |
| `history.js` | Undo/redo snapshots of the piece set |
| `pen-core.js` / `pen.js` | Pen tool math (smooth handles, point insertion) / the pen tool UI |
| `cut-core.js` / `cut.js` | Cut engine (spline ribbon, Manifold booleans, connectors, hollow-seam blocks and label pads) / cut preview and apply |
| `cutmodes.js` | Cut mode picker: Curve, Planar, Dovetail |
| `hollow-core.js` | Hybrid hollowing engine (mesh-native and grid marching cubes), plus open faces and drilled holes |
| `lamp-core.js` | Printable lamp filament glow swatch geometry |
| `bigprint-core.js` / `bigprint.js` | Big Print math (presets, grid, part IDs) / Big Print mode UI, hollow and streaming export |
| `assembly-core.js` / `assembly-viewer.js` | 3D assembly viewer: data, mesh packing, the size cap and the file text (DOM-free) / the viewer itself, runs inside `assembly.html` and in the app; never touches CC |
| `assembly-viewer-src.js` | GENERATED by `tools/embed_viewer.py` (never edit by hand): three.js, OrbitControls, fflate and the two files above as strings; loaded only on export |
| `units-core.js` / `units.js` | Units and orientation math / the Units & Orientation panel |
| `compute.js` | Dispatcher for the compute worker (repair, hollow, cut off the main thread), with main-thread fallback |
| `compute-worker-src.js` | GENERATED by `tools/embed_worker.py` (never edit by hand): the worker source with Manifold and the core engines embedded |
| `pieces.js` | Pieces panel and STL export |
| `simplify.js` | Heavy-model simplify offer |
| `analysis-core.js` / `api.js` | Mesh analysis for the page API (measure, section profile, diagnosis; DOM-free) / `CC.api`: one function per tool, `invoke(tool, args)` |
| `ai-tools.js` | The AI tool list as data (`window.CurveCutTools`, JSON after a fixed first line so Python can parse it): the one source for chat, MCP and CLI |
| `a11y.js` | Shared focus trap and reduced-motion helpers |
| `about.js`, `donate.js`, `tour.js`, `collapse.js` | About popup, donation popup, first-visit tour, panel collapse chevrons |
| `perf-hook.js`, `perf-medium-hook.js`, `perf-real-hook.js`, `race-hook.js` | Test harnesses: run only from `file:`/localhost with their `#hash` (`#perftest`, `#perfmed`, `#perfreal`, `#racetest`), driven by `tools/check_*.py` |

`cut-core.js` and `hollow-core.js` are embedded into the worker: after editing either, run `uv run --no-project python tools/embed_worker.py` and commit the regenerated `compute-worker-src.js` with them.

After editing `assembly-core.js` or `assembly-viewer.js`, run `uv run --no-project python tools/embed_viewer.py` and commit the regenerated `assembly-viewer-src.js` with them.
